AT_abc470_d [ABC470D] Inverse and Swap

2026-08-10 14:3102026-08-10 14:31

秒切 D は C で死んだ。記念して。

問題

題意より $P_{P'_i}=i$、したがって $P'$ は $P$ の逆置換であり、同時に $P'_{P_i}=i$ を満たす。入力時にこの $P'$ を前処理しておける。操作 $2$ に対してはフラグ変数 $f$ を使用する。$f=0$ なら現在操作対象は $P$ であり、$f$ を $1$ に変更することで操作対象の置換を $P'$ に切り替える。逆に $f=1$ なら $f$ を $0$ に変更し、操作対象を $P$ に戻す。操作 $1$ については $f$ が $0$ か $1$ か確認する。$0$ なら $(P_x,P_y)$ を交換し、$P'_{P_x}$ を $x$ に更新、$P'_{P_y}$ を $y$ に更新する。そうでなければ $(P'_x,P'_y)$ を交換し、$P_{P'_x}$ と $P_{P'_y}$ をそれぞれ $(x,y)$ に更新すればよい。最後に出力する。$f=0$ なら $P$ を出力、そうでなければ $P'$ を出力する。計算量 $ \mathcal O(N+Q)$、空間計算量 $\mathcal O(N)$、本問に通過可能。

✅ AC code ▶ 
#include<bits/stdc++.h>
using namespace std;
int a[int(5e5+5)],a_[int(5e5+5)];
int main(){
	ios::sync_with_stdio(false);
	cin.tie(nullptr),cout.tie(nullptr);
	int n,q;
	cin>>n>>q;
	for(int i=1;i<=n;i++){
		cin>>a[i];
		a_[a[i]]=i;
	}
	bool f=0;
	while(q--){
		int op;
		cin>>op;
		if(op==1){
			int x,y;
			cin>>x>>y;
			if(!f){
				swap(a[x],a[y]);
				a_[a[x]]=x,a_[a[y]]=y;
			}else{
				swap(a_[x],a_[y]);
				a[a_[x]]=x,a[a_[y]]=y;
			}
		}else{
			f=!f;
		}
	}
	if(!f)
		for(int i=1;i<=n;i++){
			cout<<a[i]<<' ';
		}
	else
		for(int i=1;i<=n;i++){
			cout<<a_[i]<<' ';
		}
	return 0;
}
