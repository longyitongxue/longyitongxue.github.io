题解：AT_abc432_f [ABC432F] Candy Redistribution

2026-11-15 11:50

HaoBa 题，发现自己正好错过了这场 ABC，一年后我为这题写题解。

首先如果糖果总数不是 N 的倍数的话，肯定会有孩子多拿或少拿糖果，无解，输出 − 1 。然后我们求出每个孩子当前拥有的糖果数与平均值的差，本题的目标就是通过转移糖果，把这些差值全部变成 0 。

然后我们有一个结论——一组与平均值的差值和为 0 的孩子，最少只要人数 − 1 次操作：我们选组内一个差值为负数的孩子当中转站，把组内所有差值为正数的孩子的糖果全部搬给这个中转站的孩子，再让中转站用糖果补上组内其他差值为负数的孩子的缺口。由于每个组的人数加起来肯定是 N ，前面又有每组操作次数为人数 − 1 ，那么最终答案就是 N − 组数。显然我们想要让答案最小，就要让分组尽可能多。我们找到一组差值和为 0 的孩子就马上分一组，可以证明这种方法能让我们的分组数尽可能多。

由于题目满足 N ≤ 20 ，我们使用状态压缩 DP 来实现上面的过程。我们用 mask 表示已经用掉了哪些孩子，定义 dpmask 为 mask 里所有孩子的差值最多能分出来多少组。接着我们预处理 sum mask ，表示 mask 里所有差值的和，递推式很显然就是 sum mask = sum mask ∖ { i } + 当前位孩子的差值。如果当前这个 sum 正好是 0 ，我们就立马切出一组，组数 + 1 ，否则就不增加组。因此状态转移方程就是 d p mask = max ( d p mask ∖ { i } + [ sum mask = 0 ] ) 。

最后，我们用一个 ans 数组记下让 d p mask 取到最大值时最后加入的孩子 i 。之后我们就根据上面得到的分组，模拟糖果调整的具体过程并输出操作即可。

时间复杂度 O ( N ⋅ 2 N ) ，空间复杂度 O ( 2 N ) ，可以通过本题。
