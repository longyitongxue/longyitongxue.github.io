CF1113B Sasha and Magnetic Machines

2026-08-05 15:5802026-08-05 15:58

Problem

Notice that the values of \(a_i\) are small, so we can consider a brute-force approach. We iterate \(i\) and \(j\) from \(\min\limits_{i=1}^{n} a_i\) to \(\max\limits_{i=1}^{n} a_i\). If we encounter \(i, j \in a\), we check whether \(i\) is divisible by some \(x\) (where \(x\) can be iterated over in a third loop). If so, we simply take the minimum between the current answer and the answer after the operation. The time complexity is \(\mathcal O\left(\left(\max\limits_{i=1}^{n}a_i-\min\limits_{i=1}^{n}a_i+1\right)^2\cdot\sqrt{\max\limits_{i=1}^{n}a_i}\right)\), and the total number of loop iterations is at most \(10^5\), so this solution is feasible for the problem.

✅ AC code ▶ 
#include<bits/stdc++.h>
using namespace std;
int a[int(5e4+5)];
bitset<105> vis;
int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr),cout.tie(nullptr);
    int n,ans=0,minn=2147483647,maxn=-2147483648;
    cin>>n;
    for(int i=1;i<=n;i++){
        cin>>a[i];
        vis[a[i]]=1,ans+=a[i],minn=min(minn,a[i]),maxn=max(maxn,a[i]);
    }
    int sum=ans;
    for(int i=minn;i<=maxn;i++){
        for(int j=minn;j<=maxn;j++){
            for(int k=1;k*k<=i;k++){
                if(vis[i]&&vis[j]&&!(i%k)){
                    ans=min({ans,sum-i-j+i/k+j*k,sum-i-j+i/(i/k)+j*(i/k)});
                }
            }
        }
    }
    cout<<ans;
    return 0;
}
